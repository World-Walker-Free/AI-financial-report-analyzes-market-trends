# 数据库设计（C · 数据库与后端）

> 口径依据：`需求设计文档-AI金融报告分析市场走势2.docx` 3.2 数据模型。
> 建表脚本：`sql/01_create_tables.sql`；初始化：`sql/02_init_data.sql`。
> 本地开发可用 SQLite（`backend/app.db`），字段类型与 MySQL 保持一致。

## 1. 表清单（6 表 + 1 视图）

| # | 表名 | 作用 | 主键 |
|---|---|---|---|
| 1 | `t_institution` | 机构字典 | id |
| 2 | `t_variety` | 品种字典（代码/名称/交易所/主力合约） | code |
| 3 | `t_report` | 研报元数据、文件哈希、解析状态 | id |
| 4 | `t_view` | 结构化观点（一报多条） | id |
| 5 | `t_daily_sentiment` | 每日指标快照 | (variety_code, trade_date) |
| 6 | `t_daily_price` | 研报提及价格（可选） | (variety_code, trade_date) |
| — | `v_daily_consensus` | 快照 + 品种名的查询视图 | — |

## 2. 关键字段

### t_report
- `file_hash CHAR(64)` 唯一：SHA-256 去重，重复文件直接跳过；
- `report_date`：统计日期，所有指标按它聚合；
- `parse_status`：`pending / ok / failed / need_ocr`，扫描件标 `need_ocr` 本期跳过；
- 唯一键 `(file_hash)`；索引 `(report_date)`、`(institution_id, report_date)`。

### t_view
- `direction`：`BULL / BEAR / NEUTRAL / UNKNOWN`，**UNKNOWN 不计入指数**；
- `confidence DECIMAL(3,2)`：只统计 ≥ 0.6 的；
- `horizon`：`intraday / short / medium`，**不同周期分开统计**；
- `evidence`：原文依据，用于溯源；
- 索引 `(report_id)`、`(variety_code, direction)`。

### t_daily_sentiment
- `bull_count / bear_count / flat_count`：去重后的机构家数；
- `institution_count = B + S + F`；
- `consensus_index DECIMAL(5,1)`，**N=0 时为 NULL**；
- 主键 `(variety_code, trade_date)` 保证重算幂等（先删后插）。

## 3. 指数与去重口径

```
I = (B - S) / N × 100 ,  N = B + S + F
```

1. 只取 `direction ∈ {BULL, BEAR, NEUTRAL}` 且 `confidence ≥ 0.6`；
2. 同一机构 + 同一品种 + 同一交易日只算一次，取置信度最高的一条；
3. 未提及该品种的机构不进分母；
4. `N = 0` → `NULL`，前端显示 `-`；
5. 重算接口幂等：同一日期重复执行结果不变。

## 4. 索引与性能

| 表 | 索引 | 用途 |
|---|---|---|
| t_report | `ix_report_date`、`ix_report_inst_date` | 按日查询、按机构统计 |
| t_view | `ix_view_report`、`ix_view_variety_dir` | 溯源、按品种方向聚合 |
| t_daily_sentiment | 主键 + `ix_sent_date` | 概览/历史/排行全部走快照 |

接口层只查 `t_daily_sentiment`（预聚合），不实时扫 `t_view`，保证 P95 ≤ 500ms。

- 开发：SQLite（零配置），`DATABASE_URL=sqlite:///./app.db`；
- 部署：MySQL 8.0 / MariaDB 10.4（`nailong`），
  `DATABASE_URL=mysql+pymysql://nailong:woshinailong@<host>:3306/project_8?charset=utf8mb4`；
- 建库执行：`mysql -u nailong -p < sql/01_create_tables.sql`，再执行 `02_init_data.sql`。
